# SWCraft 0.4.2

A one-line patch release from `release/0.4`, for the demonstration track. The model contract,
the editing protocol, the MCP tool surface and the emitted ARXML bytes are unchanged from 0.4.1;
a 0.4.x project upgrades by installing the four artifacts.

```
swcraft-tools==0.4.2
swcraft-mcp==0.4.2
swcraft-agent==0.4.2
```

plus `swcraft-vscode-0.4.2.vsix`.

## Scaffolded projects ignore LikeC4's `.likec4/` cache

Opening the LikeC4 preview creates a `.likec4/` directory in the project root. Found on the
2026-08-25 Windows first run, where it left a freshly scaffolded project's working tree dirty
after the very first diagram — against the "commit source inputs only" rule every showcase
project follows. LikeC4 is a member of the extension pack SWCraft ships, so its cache is
predictable tool output; the template's `.gitignore` now lists `.likec4/` beside `dist/`,
`views/`, `.venv/` and `.moon/cache/`, guarded by `TestTemplateGitignore`.

An existing project adds the line to its own `.gitignore`; `swcraft init` does not rewrite that
file.
