# How-to

<!-- purpose: Typical tasks, step by step, by hand in the editor and through the assistant -->

<!-- keywords: how to, how do i, recipe, step by step, task, list of tasks, scenario, cookbook, example -->

<!-- How this section grows: a page is added when a typical task is added to the measured set of

Each page here is one typical task, written once for you and for the assistant. Every page has
the same shape: what the task is for, what must exist first, the names you need and how to find
yours, the steps — the action in VS Code or on the command line beside the call the assistant
makes — what you get, how to check it, and the refusals you may meet. Names from
`examples/basic` are used as they are; a name it does not have is marked *example*. On the pages
that ask a question, a name in angle brackets in a call — `<COMPONENT>` — stands for yours.
