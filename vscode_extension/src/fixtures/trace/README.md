# The Trace Links view's model fixture

A small synthetic model, generic names only, on which `traceCore.test.ts` locates
every target kind (`traceElementLocation`) and enumerates a component's members
(`componentMembers`, both block-list layouts). Not a buildable model; no CLI runs
on it. `swc/app/brake~1.yaml` is the case-insensitive twin of `Brake.yaml`.
